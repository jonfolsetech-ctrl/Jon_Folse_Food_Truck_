# Contributing

Thanks for helping improve the Jon Folse Food Truck website.

## Local workflow

1. Install Node.js 22.13 or newer and pnpm 11.19.
2. Run `pnpm install`.
3. Create a branch from `main`.
4. Make focused changes and preserve the established navy, antique-gold, and aged-ivory brand system.
5. Run `pnpm run check` before opening a pull request.

## Content rules

- Keep the business name as **Jon Folse Food Truck**.
- Do not claim endorsements, partnerships, or licensing relationships with Chef John Folse.
- Keep unconfirmed prices, schedules, contact details, and locations clearly marked as placeholders.
- Confirm spelling, accessibility labels, and mobile behavior for customer-facing changes.

## Pull requests

Describe what changed, why it changed, and how it was checked. Include screenshots only when the visual design changed.
